Esse projeto foi desenvolvido com as seguintes tecnologias:

- JavaScript
- Git e Github
- Figma

## 💻 Projeto

O DevLinks é um agregador de links para usar como cartão de visitas online. Esta versão inclui uma transição suave e customizada dos ícones de fundo durante a troca de tema (Claro/Escuro).
